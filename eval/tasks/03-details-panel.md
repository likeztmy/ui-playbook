# Order details

A shop's admin. Build the page for order **#10482**: customer, items, totals, and three panels that
expand and collapse: **Shipping details** (address, carrier, tracking number, delivery estimate),
**Payment details** (card, billing address, refunds) and **Order history** (eight timestamped
events). Each panel is opened and closed from its own header. Shipping details starts open; the
others start closed.
