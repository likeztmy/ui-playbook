# Delete a project

A project management tool. Build the settings page of the project **Q4 roadmap** (48 issues,
6 members). At the bottom, a **Danger zone** section has a **Delete project** button.

Deleting removes the project and all its issues for everyone, and can't be recovered, so pressing
the button asks before doing it. If the person goes ahead, they land on a **Projects** list that no
longer has Q4 roadmap in it (invent four other projects). If they back out, nothing changes.
