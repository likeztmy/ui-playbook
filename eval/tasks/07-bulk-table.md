# Files

A cloud drive's file table: 40 files and folders (invent them), with Name, Owner, Modified and
Size columns, sortable.

Rows can be selected, one, several or all. With a selection, the person can **Move to…** a folder,
**Download** or **Delete** the selected files. Deleted files go to Trash, which isn't part of this
task.
