# Command menu

A notes app. Build its main screen (a note open, with a toolbar) and a command menu for it.

The menu opens with ⌘K (Ctrl+K on Windows) or from a **Search or jump to…** button in the toolbar.
It lists actions (New note, Duplicate note, Move to folder…, Export as PDF, Toggle dark mode,
Settings) and the 30 most recent notes (invent them). Typing filters both. The arrow keys move
through results and Enter runs the one picked; picking a note opens it. Some actions have keyboard
shortcuts of their own; show them.
