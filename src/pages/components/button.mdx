## When to use

A button runs an action now. Navigation is a link, even when it looks like a button; a state that stays is a Switch or a Segmented control; more actions than room go in a pull-down Menu, with the main one left visible.

## Variants

<ButtonVariants client:visible />

Pick by weight, not by colour: primary for the reason the view exists, secondary for everything else, ghost to step back. The danger pair marks destruction, as text among ordinary actions or as the one fill in a confirm dialog.

## Anatomy

| Part | Token | Value |
| --- | --- | --- |
| Height | `control-md` · `control-sm` · `control-lg` | 32 · 24 · 40 |
| Horizontal padding | `space-3` (sm: `space-2`, lg: `space-4`) | 12 |
| Radius | `radius-full`, every size | pill |
| Icon gap | `space-1` | 4 |
| Label | body, weight 500 | 14 / 20 |
| Fill | `fill-control` · hover `fill-control-hover` | |
| Hover | in `duration-instant`, out `duration-fast` | 0 · 120 |
| Press | `press-scale` in 80ms, back on `ease-spring-snappy` | 0.97 |
| Busy | after `delay-loading`; Lucide `loader-circle` in the icon slot | 300 |

Buttons in one row share one height. An icon-only button always has a tooltip with the same words as its `aria-label`. While busy it stays focusable but ignores presses until the request settles.

## States

<ButtonStates client:visible />

Secondary is a fill (`fill-control`), translucent ink, so one value works on any surface and in both themes. Focus shows only on `:focus-visible`: a mouse click never draws a ring.

## Common mistakes

- **A shadow to lift it.** Fill is the signal; a shadow makes it a card.
- **Colour as rank.** Two secondary buttons in different colours ask the reader to learn a code. Use variants: primary, secondary, ghost.
- **Disabled with no reason.** If the action can't run yet, say why nearby, or leave the button enabled and explain on press.

## Copy

- Start with a verb that names the result: **Save changes**, **Create project**, not *OK* or *Submit*.
- Sentence case: **Create project**, not *Create Project*.
- Match the dialog's title: a dialog called *Delete project?* confirms with **Delete project**.
