## When to use

Tabs switch between views of one thing, each replacing a region of the page. A mode of one control is a Segmented control; views with their own URL are navigation; past about six, a sidebar or a Select; steps in order want a flow.

### Tabs or segmented control

| | Tabs | Segmented control |
| --- | --- | --- |
| Switches | A region of the page | One control's mode |
| Looks like | Labels on a line, a bar under the current one | A filled track with a raised segment |
| Count | 2 to about 6, can scroll | 2 to 5, never scrolls |
| Sits | Above the content it changes | Beside the thing it changes, often in a toolbar |

## Anatomy

| Part | Token | Value |
| --- | --- | --- |
| Tab height | 40 | 40 |
| Between tabs | `space-4` | 16 |
| Label | 14 / 20, weight 500 | 14 |
| Default | `ink-muted` | |
| Current | `ink` | |
| Bar | 2px, `ink`, `radius-full` | 2 |
| Line | 1px `line`, the full width of the tabs | 1 |
| Count | mono 11, `surface-sunken`, `radius-full` | 18 |
| Panel gap | `space-4` | 16 |

The bar sits on the line, under the label's full width. Tabs have no side padding: the gap is the only space between them, so labels line up with the content's left edge.

## States

<TabsStates client:visible />

Each arrow moves to the next tab and opens it, since the panels appear at once; Home and End jump to the ends, and Tab moves into the panel. The bar slides to the new tab and takes its width on the smooth spring (`ease-spring-smooth`).

## Common mistakes

- **Tabs that hide required input.** If a form spans tabs, people submit without seeing half of it. Put it on one page, or make it a flow.
- **Controls above the tabs that act on one panel.** Apple: controls in a pane affect only that pane. Move them inside.
- **Tabs that reset.** Coming back to a page should show the tab people left, not the first one.
- **A single tab.** One view needs a heading, not a tab.

## Copy

- Labels: nouns or short noun phrases, one or two words: **Overview**, **Pull requests**.
- Sentence case, as everywhere here; Apple's title case is the platform's, not ours.
- Parallel: all nouns, or all verbs. Not *Overview*, *Manage members*, *Billing*.
