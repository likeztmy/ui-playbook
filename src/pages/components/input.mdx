## When to use

For text people type: a name, an address, a number with a unit. Reach for something else when the answer is one of a few known values (radios, a Select, or a combobox for many), on or off (a Switch or a Checkbox), or a position on a range (a Slider).

- **Leading end: what the field is for.** A magnifier on a search. Nothing on a plain field: the label already says it.
- **Trailing end: what the field offers.** A unit, a shortcut key, a clear button. One at most.

| Part | Token | Value |
| --- | --- | --- |
| Height | `control-md` | 32 |
| Radius | `radius-lg` | 10 |
| Edge | `line-strong`, 1px | |
| Padding | `space-3` | 12 |
| Trailing inset | 4 from the outer edge: 1 border + 3 | 4 |
| Embedded key | 24 tall, `radius-sm` = 10 − 4 | 6 |
| Label | label, 12 / 16, weight 500, `ink-muted` | 12 |
| Label, field, hint | `space-1` apart | 4 |
| Focus | the edge turns `accent`, nothing around it | 1 |
| Text | 14 / 20; 16 on touch screens | 14 |

The label sits above, the hint or the error below, never both: the error takes the hint's line. The field keeps its outline because an empty box has nothing else to say it can be filled; the focus ring a button uses would float 2px off an edge that's already there.

## Known issues

- **iOS Safari zooms into text under 16px** when a field takes focus. Fields use 16px on touch screens (`pointer: coarse`).
- **`type="email"` answers first**, with the browser's own message in the browser's language. Use `type="text"` with `inputMode="email"`, so the phone still shows the @ keyboard.

## Common mistakes

- **A hint that repeats the label.** *Enter your email* under **Email** says nothing. Keep the line for a format, a limit, or a consequence.
- **Clearing the field on error.** Keep what they typed; they're usually one character away.
- **Read-only drawn as disabled.** Read-only text can still be selected and copied, so it keeps the ink colour.

## Copy

- Label: a noun, sentence case, no colon: **Email**, **Postal code**.
- Placeholder: an example, not an instruction: **{'ana@studio.com'}**, not *Enter your email*.
- Error: what to do, with an example if the format is the problem: **Enter a 5-digit postal code, like 10115.** Never *Invalid input*.
