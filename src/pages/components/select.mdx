## When to use

A Select picks one value from a short, flat list of choices that exclude each other. Apple calls it a pop-up button. Reach for something else when:

- **There are two to four options.** Show them all: a segmented control or radios. Opening a list to see two words is a wasted click.
- **There are more than about fifteen, or people know what they want.** A combobox lets them type.
- **The options are actions.** *Duplicate*, *Archive*, *Delete* belong in a Menu: a pull-down that does something, not a value that stays.
- **More than one can be chosen.** Checkboxes, or a Menu with checkbox items.

### Select or Menu

| | Select | Menu |
| --- | --- | --- |
| Trigger shows | The current value | A fixed label or icon |
| Picking a row | Changes the value | Runs an action |
| Chevron | Up and down | Down |
| Opens | Over the trigger | Below the trigger |
| Rows | Text only | Icons, shortcuts, submenus |

## Anatomy

| Part | Token | Value |
| --- | --- | --- |
| Trigger | as Input: `control-md`, `radius-lg`, `line-strong` | 32 |
| Chevron | 16px, `space-2` from the right | 16 |
| List | as Menu: `radius-lg`, inset `space-1`, rows `control-md` | 10 |
| List width | the trigger's, or wider for a long option | |
| Current option | weight 500, leading `accent-text` check, no fill | |
| Keyboard highlight | `fill-active` | |
| Layer | `z-dropdown` | 100 |

Opened over the trigger, the list shifts left so the current option's text lands exactly on the trigger's, and its check hangs in the column to the left, as on macOS. The list widens by that column so it still covers the trigger.

## Common mistakes

- **A Select for Yes / No.** Two options are a Switch or a segmented control.
- **A Select that runs commands.** If picking a row doesn't leave a value behind, it's a Menu.
- **An empty first option as the placeholder.** It can be picked back. Use the placeholder, and only when the field has no fair default.
- **Long sentences as options.** Options are names. If they need explaining, use radios with descriptions.

## Copy

- Label: what the value is, a noun: **Role**, **Font**.
- Options: short, sentence case, parallel in form: **Owner**, **Admin**, **Editor**.
- Placeholder, when there is one: **Choose a reason**, not *Select…*.
