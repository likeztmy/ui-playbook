## Anatomy

| Part | Token | Value |
| --- | --- | --- |
| Popup radius | `radius-lg` | 12 |
| Popup inset | `space-1` | 4 |
| Item radius | `radius-md` = 12 − 4 | 8 |
| Item height | `control-md` | 32 |
| Item padding, icon gap | `space-2` | 8 |
| Label | body-sm size, 13 / 18 | 13 |
| Keycap | 18 square, `radius-xs`, `surface-sunken` | 18 |
| Surface | `surface-raised`, `shadow-md` | |

Icons are Lucide at 16px in `ink-muted`, turning `ink` on the highlighted row. Checkmarks and submenu chevrons sit to the right of the label; shortcuts end the row.

## States

<MenuLive client:visible />

Open it and use the keyboard. Arrows move the highlight, Right opens *Move to*, and Space toggles *Snap to grid* without closing the menu. Undo can be reached but not run: disabled menu items stay focusable so a screen reader still announces them. Pointer and keyboard share one highlight (`data-highlighted`), with no transition in either direction.

### The popup comes out of its trigger

<MenuMotion client:visible />

Opening uses `duration-base` with `ease-out`, from 4px toward the trigger. Closing is half as long with `ease-in`: once the user has chosen, nothing should hold them up. With reduced motion, only a short fade remains.

## Common mistakes

- **A group label that repeats the trigger.** A menu opened from *Edit* doesn't need an *Edit* heading. Separators group; add a label only when filtering or length mixes groups.
- **Destructive actions mid-list.** Put them in the last group, in `danger`, where a slip of the pointer is least likely to land.
- **Closing on every toggle.** A checkbox item stays open so several options can be set in one visit.
- **Disabled items that vanish.** Keep them in place in `ink-disabled`, so the menu's layout doesn't shift between contexts.

## Copy

- Items are verbs or verb phrases: **Duplicate**, **Move to**. An ellipsis means a dialog follows: **Rename…** if it opens one, **Rename** if it edits in place.
- Keep one grammatical form within a menu.
