## When to use

A slider tunes a value you judge by eye while watching the result: an opacity, a radius, a spring's bounce. This one is built for property panels, after DialKit: the whole row is the control. Reach for something else when:

- **People know the exact number.** A number field takes *1280* faster than any drag. Offer both when either happens.
- **There are a few named options.** *Small*, *Medium*, *Large* is a segmented control.
- **It's a range with two ends.** A two-thumb slider is its own component; don't stack two of these.
- **The change is expensive.** A slider fires continuously; if each value costs a request, commit on release or use a field.

## Anatomy

| Part | Token | Value |
| --- | --- | --- |
| Row | `control-md`, `radius-lg`, `fill-control` | 32 |
| Fill | another `fill-control`; hover `fill-control-hover` | |
| Label | 13 / 500, `space-3` from the left | 13 |
| Value | Geist Mono, `tabular-nums`, `space-3` from the right | 13 |
| Handle | 3 × 16, `radius-full`, `ink` | 3 |
| Ticks | 1 × 8, `line-strong`, ten stops or fewer | 8 |
| In a panel | `radius-xl` 18, inset `space-2` 8 → row `radius-lg` 10 | 10 |

Label and value are `ink-muted` at rest and `ink` while the row is hovered, dragged or focused.

## Common mistakes

- **No visible value.** A slider without a number makes people drag back and forth to find out where they are.
- **A slider for a precise number.** Three-digit precision by dragging is a test of hand steadiness. Pair it with a field.
- **Steps finer than the pixels.** A 0–10,000 range on a 280px row skips values; drop the step or narrow the range.
- **Animating keyboard steps.** Arrow presses come in bursts; each should land at once.

## Copy

- Label: the property, a noun: **Opacity**, **Radius**, **Columns**.
- Value: the number with its unit attached: **64%**, **12px**. A bare number when the unit is obvious from the label: **Columns 3**.
