## When to use

A work tool that should feel like Linear: white behind the work, near-black text, greys for everything but one indigo, controls as pills, 13px Inter on hairline edges. The values are read from Linear's own app (its CSS variables and computed styles, in its Pure Light and Dark themes), with its typefaces from [the redesign](https://linear.app/now/how-we-redesigned-the-linear-ui).

## Where it differs from Linear

- **The focus ring is 2px.** Linear draws a 1px ring; the playbook's 2px holds 3:1 against more backgrounds.
- **The accent's hover and text colours are derived, not read.** Here they are the accent a step darker, and lightened for text on dark.
- **One radius is a guess.** The small radius is a variable Linear defines but no control was seen using it.
