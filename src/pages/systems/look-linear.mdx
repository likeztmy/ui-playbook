## When to use

A work tool that should feel like Linear: a cool near-white behind the work, near-black text, and Inter. Linear publishes little that's visual: two brand neutrals ([Linear brand](https://linear.app/brand)) and its typefaces ([the redesign](https://linear.app/now/how-we-redesigned-the-linear-ui)). Everything else here is the playbook's, which already holds the same habits: grey surfaces, one accent, dense rows.

## Where it differs from Linear

- **Its theme isn't published.** Linear generates its themes in LCH from a base colour, an accent and a contrast setting, but doesn't publish the numbers, so the surfaces, lines, accent and dark theme are the playbook's.
- **Inter Display is for headings.** Load Inter with its display optical size, or Inter Display beside it, for titles; body text is Inter.
